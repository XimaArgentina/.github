# xima

Software para PyMEs argentinas, operado con IA.

- **XIAgenda** — turnos para consultorios de salud, con un agente de IA sobre WhatsApp.
- **XNómina** — liquidación de sueldos y recibos.

---

## 👋 ¿Encontraste algo? Reportalo acá

| Producto | Link |
|---|---|
| **XIAgenda** (turnos) | [Reportar →](https://github.com/XimaArgentina/xiagenda/issues/new/choose) |
| **XNómina** (sueldos) | [Reportar →](https://github.com/XimaArgentina/xnomina/issues/new/choose) |

Guardate esos dos links. **No tenés que ordenar nada**: escribí como le contarías a un
compañero y una IA se encarga del formato, las etiquetas y el tablero.

📄 **[Cómo reportar — guía completa](https://github.com/XimaArgentina/.github/blob/main/REPORTAR-CON-IA.md)**
· incluye cómo hacerlo **hablándole a ChatGPT o a Claude** en vez de llenar un formulario.
